# JavaScript Practice Problems

A collection of 10 beginner-level JavaScript problems solved as part of my Full Stack Development learning journey.

## Topics Covered

- Variables and Operators
- Conditional Statements (`if`, `else`)
- Switch Statements
- Ternary Operators
- Functions and Arrow Functions
- Return Statements
- For and While Loops
- Nested Loops
- Mathematical Operations
- Number Manipulation
- Basic Problem-Solving Logic

## Practice Problems

1. Student Marks, Grade, Result & Remarks
2. Result Evaluator – Pass or Fail
3. Maximum Finder – Largest of Three Numbers
4. Accumulator – Sum from 1 to N
5. Multiplication Table Generator
6. Digit Counter – Number Length Finder
7. Number Reverser
8. Factorial Calculator
9. Prime Number Validator
10. Pattern Builder – Star Triangle

## Technologies Used

- JavaScript
- Node.js
- Visual Studio Code


## Learning Goal

To strengthen JavaScript fundamentals, improve logical thinking, and develop independent problem-solving skills through hands-on practice.

This repository documents my learning progress, experiments, debugging, and problem-solving journey.
